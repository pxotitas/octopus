como as cores funcionam

instalar

no arch (ou o que tiver esses pacotes), o repo mora no próprio ~/.config/octopus. o instalador pergunta antes das partes opcionais, como o octopus files.

git clone https://github.com/pxotitas/octopus ~/.config/octopus
~/.config/octopus/install.sh

depois, no fim do ~/.config/niri/config.kdl:

include "~/.config/octopus/niri.kdl"
